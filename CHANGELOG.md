# Changelog

Формат: заметные изменения по версиям.

## 0.3.0

### Исправления
- Окно уведомления больше не появляется сразу при создании заметки (время по умолчанию = +1 час)

### Новые возможности
- Расширенное меню "Отложить" (Outlook-style): 5/10/15/30 мин, 1/2/4 часа, 1 день, 1 неделя
- Цветные категории (Outlook-style): без категории, жёлтая, зелёная, красная, лиловая, оранжевая, синяя
- Время начала события + "Напомнить за": выбор за сколько до начала показать уведомление

### Улучшения UI
- Оптимизированный layout: 2 строки (Начало/Важность/Категория + Напомнить/Автоскрытие)
- Минимальный размер окна 900×600
- Улучшенное масштабирование элементов
- В окне уведомления рядом с названием отображается дата и время начала события

## 0.2.0

- Единый WYSIWYG‑редактор (RichEdit) как основной режим редактирования
- Вставка изображений в заметки (RTF `\pict\pngblip`) + хранение медиа в папке заметки
- “Идеальный” предпросмотр уведомления в главном окне (макет 1:1)
- Уведомление по центру экрана + корректное масштабирование
- Кнопка “Отложить” (5/10/30/60 минут)
- Настройки звука: вкл/выкл + системные алиасы или WAV для уровней важности + “Тест звука”
- Автосохранение с защитой от потери правок (debounce + flush перед критичными действиями)
- Календарь: метаданные дня (важность/превью) и применение темы
- Темы Premium/Minimal (единый `UiTheme`)
